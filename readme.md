## 로컬에서 보기

저장소를 클론한 뒤, 루트에서 정적 서버를 띄우면 됩니다.

```bash
git clone https://github.com/sogwon/sogwon.github.io.git
cd sogwon.github.io
# Python 3
python3 -m http.server 8000
# 또는 npx
npx serve .
```

브라우저에서 `http://localhost:8000` 으로 접속하면 메인 페이지를 볼 수 있습니다.

## 기술

- 정적 HTML/CSS, 미니멀 모노크롬 디자인
- 반응형 레이아웃 (모바일 대응)
- QR코드는 [api.qrserver.com](https://api.qrserver.com/) API로 메인 페이지에서 실시간 생성
